# Japan Survival Map: Umeda - 現在の実装状況

更新日: 2026-06-14

## 1. プロダクト概要

梅田・大阪駅周辺を訪れる旅行者向けの、スマートフォン優先の地図PWAです。
トイレ、コインロッカー、ゴミ箱、ATM、喫煙所、駅出口を、地図と一覧から探せます。

現在の実装は、当初のMVPに加えて、ユーザー投稿、問題報告、日英切替、任意のSupabase同期まで含んでいます。

## 2. 現在の技術構成

- Next.js 14.2.5（App Router）
- React 18.3.1
- TypeScript 5.6.2
- Tailwind CSS 3.4.5
- MapLibre GL JS 5.24.0
- OpenFreeMapの地図スタイル・タイル
- `next-pwa`によるService Worker生成
- PlaywrightによるE2Eテスト
- ローカルJSONと`localStorage`を中心としたデータ保存
- Supabase REST APIへの任意同期（環境変数設定時のみ）

認証、管理画面、専用バックエンドはありません。

## 3. 実装済み機能

### 地図・スポット検索

- 梅田周辺を初期表示する単一画面の地図
- 6カテゴリの絞り込み
  - Toilet
  - Coin locker
  - Trash bin
  - ATM
  - Smoking area
  - Station exit
- カテゴリごとに色分けされた地図マーカー
- マーカーのポップアップから詳細表示
- スポット一覧からの詳細表示
- 一覧は最大10件を表示
- 現在地取得成功時は距離順に並び替え
- 現在地取得成功時は地図上に現在地マーカーを表示
- 位置情報拒否・未対応・タイムアウト時は梅田中心を使って継続表示

### スポット詳細

- ボトムシート形式の詳細表示
- 名称、カテゴリ、説明、旅行者向けメモ、営業時間、支払い情報、駅構内外、タグを表示
- 現在地がある場合は直線距離を表示
- Verified / Needs reviewの状態表示
- Last checkedの日付表示
- Google MapsおよびApple Mapsへの外部リンク
- 営業時間などが変わる可能性を示す注意文

### ローカル投稿

- 新規スポット追加
- ユーザーが追加したスポットの編集・削除
- 緯度・経度の直接入力
- 位置情報取得済みの場合は現在地を初期座標として使用
- 投稿内容を`localStorage`へ保存し、リロード後も維持
- ユーザー投稿は未確認状態として表示

### 問題報告

- 各スポットから問題報告フォームを表示
- 閉鎖・場所違い・営業時間違い・安全性や清潔さ・その他を選択可能
- 詳細テキストを入力可能
- 報告を`localStorage`へ保存
- オフライン時もローカルキューとして保持

### 多言語

- English / 日本語のUI切替
- 選択言語を`localStorage`へ保存
- HTMLの`lang`属性も選択言語に合わせて更新

スポット名や説明など、シードデータ自体は英語のみです。

### PWA・オフライン

- Web App Manifest
- standalone表示、portrait指定、テーマカラー設定
- 通常アイコンとmaskableアイコン
- 本番ビルド時にService Workerを生成・登録
- アプリシェル、JS/CSS、画像、OpenFreeMap資産のランタイムキャッシュ
- ネットワーク障害時の`offline.html`フォールバック
- 開発モードではPWA機能を無効化

### 任意のSupabase同期

以下の環境変数がある場合のみ有効になります。

```text
NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_ANON_KEY
```

- ユーザー投稿を`pending_review`としてREST APIへ送信
- 問題報告をREST APIへ送信
- `active`状態の承認済みスポットを取得
- 承認済みスポットを30秒間隔で再取得
- ローカル投稿と同じIDのリモートデータは重複表示しない
- 同期失敗時もローカルデータで利用継続

Supabaseクライアントパッケージは使わず、REST APIを直接呼び出しています。

## 7. 当初方針との主な差分

`AGENTS.md`の記載と現在の実装には、次の差分があります。

| 当初方針 | 現在の実装 |
| --- | --- |
| Leaflet + OpenStreetMap | MapLibre GL JS + OpenFreeMap |
| UIは英語のみ | English / 日本語切替あり |
| Supabase・DBロジックをまだ導入しない | 任意のSupabase REST同期あり |
| MVP中心 | 投稿、編集、削除、報告、承認済みデータ取得まで拡張 |

この差分は不具合ではありませんが、今後の正式なプロダクト方針として維持するか、MVPへ戻すかを決める必要があります。

## 8. 現時点の課題・リスク

### データ品質

- 25件すべてが同じ確認日・確認済み状態で、実地確認の根拠はコード上にありません。
- `Sample Demo Smoking Spot`など、公開データとして再確認が必要そうな名称があります。
- 営業時間、設備状態、駅構内の導線は変化しやすく、継続更新の運用が未定です。

### UX

- 一覧は最大10件で、11件目以降を見るページングや「もっと見る」がありません。
- 投稿時に地図をタップして位置を指定できず、座標を直接入力する必要があります。
- Bottom Sheetとフォームは見た目上モーダルですが、フォーカストラップやEscapeキー対応は未確認です。
- カテゴリ名、報告種別、スポット本文など一部の表示は日本語UIでも英語のままです。

### オフライン・PWA

- PWAとキャッシュは本番ビルドでのみ有効です。
- 実機でのインストール、更新、完全オフライン起動は自動テストされていません。
- 地図キャッシュは閲覧済み資産に依存するため、未閲覧エリアまで完全オフラインで使える保証はありません。

### 同期・運用

- Supabaseのスキーマ作成やRow Level Security設定は自動化されていません。
- 管理画面と承認操作は未実装です。
- 同期のE2Eテストはありません。
- ローカル投稿は同期成功後もローカルに残り、同期済み状態をユーザー投稿側に保持していません。
- 30秒ポーリングで、Realtimeは未実装です。

### ドキュメント

- `docs/screen-flow.md`にはLeafletや未実装のSettings画面など、現状と異なる記述があります。
- `docs/manual-test-spec.md`は文字化けしており、そのままでは利用困難です。
- `docs/schema.md`は現在の`verified`、`lastChecked`や問題報告スキーマを十分に反映していません。
- READMEと`AGENTS.md`でプロダクト方針が一致していません。
